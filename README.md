Este é site FocoQuest, possui funcionalidades, como login/Cadastro, gerenciamento de tarefas(Kanban e quests), possui um temporizador(É novo). Você começará na página incial, no footer terá algumas páginas e após clicar em iniciar sessão você será levado para o Login e cadastro, após o login ou cadastro do usuário, o site de redirecionarar para a Home(Cronograma, Quests, Kanban, Pomodoro, Guilda, Inventário, Configurações).

// Navegação

-Iniciar Sessão:
    Entrar;
    Continuar com Google;
    Cadastrar.

-Cadastrar;

    Configurações.
